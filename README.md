## Key WiFi - Simple Deauth Tool

Tools deauth sederhana dengan Python.  
Dibuat agar proses aktifkan mode monitor & deauth lebih mudah digunakan.

## Warning!!

Tools ini hanya support pada Ubuntu, Kali Linux, dan Parrot Security.

## Cara penggunaan

```bash
git clone https://github.com/keydo5507-del/Key-WiFi.git
cd Key-WiFi
